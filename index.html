กำหนดเวลาเปิด-ปิด การลงคะแนน

จัดการรายชื่อผู้มีสิทธิ์ลงคะแนน (Eligible Voters)

ตรวจสอบและติดตามสถานะการใช้สิทธิ์ของสมาชิก

เลขสมาชิก ชื่อ - นามสกุล สังกัด / โรงเรียน สถานะการลงคะแนน เวลาที่ลงคะแนน จัดการ

จัดการข้อมูลผู้สมัครรับเลือกตั้ง

หมายเลข ชื่อ-นามสกุล สังกัด / โรงเรียน / หน่วยเลือกตั้ง จัดการ

การจัดการผลคะแนนและการรีเซ็ตระบบ

รีเซ็ตคะแนนเสียงให้เหลือ 0 (Reset Votes to 0)

ล้างเฉพาะคะแนนเสียงที่ลงไว้ทั้งหมดให้กลับเป็น 0 คะแนน และคืนสิทธิ์ให้สมาชิกทุกคนสามารถลงคะแนนได้ใหม่
✓ รายชื่อผู้มีสิทธิ์และรายชื่อผู้สมัครจะไม่ถูกลบ

รีเซ็ตระบบทั้งหมดเป็นค่าเริ่มต้น (Reset All)

ล้างคะแนนทั้งหมด คืนสถานะผู้มีสิทธิ์ให้ยังไม่ลงคะแนน และเปิดระบบพร้อมลงคะแนนใหม่ทันที

ถ่ายโอนข้อมูลและย้ายไปใช้เครื่องอื่น (Multi-Device & Backup)

แก้ปัญหาข้อมูลไม่ตามไปเมื่อเปิดในเบราว์เซอร์อื่น หรือเครื่องคอมพิวเตอร์อื่น

ดาวน์โหลดไฟล์ HTML พร้อมข้อมูลปัจจุบัน

ระบบจะนำรายชื่อผู้มีสิทธิ์ที่นำเข้าไว้, ผู้สมัคร และรหัสผ่านปัจจุบัน เขียนฝังลงในไฟล์ HTML ให้โดยตรง
✓ นำไฟล์ใหม่นี้ไปเปิดเครื่องไหน เบราว์เซอร์ไหน ข้อมูลจะติดไปด้วยทันที 100%

ส่งออก / นำเข้าไฟล์สำรองข้อมูล (.json)

ส่งออกไฟล์ข้อมูลสำรองเพื่อเก็บไว้ หรือนำไฟล์ไปกู้คืนในเครื่องอื่น/เบราว์เซอร์อื่นได้ทันทีใน 1 วินาที

คำแนะนำเกี่ยวกับการใช้งาน:
  • ใช้งานเครื่องเดียว (Single Station): ใช้เครื่องคอมพิวเตอร์ 1 เครื่องเป็นคูหาลงคะแนน สมาชิกเดินมาลงคะแนนทีละคน คะแนนจะบันทึกรวมในเครื่องนั้นตลอดไป
  • ย้ายไปเปิดเครื่องอื่น (Standalone / Offline): กดปุ่ม "ดาวน์โหลดไฟล์ HTML พร้อมข้อมูลปัจจุบัน" ด้านบน แล้วนำไฟล์ใหม่ไปเปิดเครื่องอื่นได้ทันที
  • ใช้งานหลายเครื่องพร้อมกัน (Multiple Voting Booths): หากมีคูหาลงคะแนน 2-3 เครื่อง และต้องการให้คะแนนวิ่งมารวมกันที่จอหลักแบบ Real-time โปรดแจ้งผู้พัฒนาเพื่อเปิดระบบเชื่อมต่อ Cloud Database (เช่น Firebase) หรือ Local Web Server ในวง Wi-Fi โรงเรียน
